# Password Reset Guide

## Resetting Your Password

### Via Login Page

1. Go to the login page
2. Click "Forgot Password?" below the login button
3. Enter your email address
4. Click "Send Reset Link"
5. Check your email for a password reset link (check spam folder if not received)
6. Click the link in the email (valid for 1 hour)
7. Enter your new password (must meet requirements)
8. Click "Reset Password"
9. You'll be redirected to the login page

### Password Requirements

Your new password must:
- Be at least 12 characters long
- Include at least one uppercase letter
- Include at least one lowercase letter
- Include at least one number
- Include at least one special character (!@#$%^&*)
- Not be the same as your last 5 passwords
- Not contain your email address or username

## Troubleshooting

### Not Receiving Reset Email

**Check these common issues:**
1. Verify you entered the correct email address
2. Check your spam/junk folder
3. Add noreply@company.com to your safe senders list
4. Wait 5-10 minutes (emails can be delayed)
5. Try requesting another reset link

**Still not receiving emails?**
- Contact support at support@company.com
- Include your username and registered email
- Support can manually reset your password

### Reset Link Expired

Reset links expire after 1 hour for security. If your link expired:
1. Return to the login page
2. Click "Forgot Password?" again
3. Request a new reset link

### Password Doesn't Meet Requirements

If you see an error message about password requirements:
- Read the error message carefully
- Ensure your password meets ALL requirements listed above
- Avoid common passwords (e.g., "Password123!")
- Use a password manager to generate a strong password

### Account Locked After Multiple Attempts

Accounts are locked after 5 failed password attempts:
- Wait 30 minutes for automatic unlock
- OR request a password reset (recommended)
- OR contact support for immediate unlock

## Security Best Practices

### Creating a Strong Password
- Use a passphrase (e.g., "Coffee!Drinker@Morning99")
- Use a password manager (1Password, LastPass, Bitwarden)
- Never reuse passwords across different sites
- Change your password every 90 days

### Protecting Your Password
- Never share your password with anyone
- Don't write passwords down
- Don't email your password to anyone
- Enable two-factor authentication for additional security

### Suspicious Activity
If you notice suspicious activity:
1. Reset your password immediately
2. Review recent login activity (Account Settings > Security)
3. Enable two-factor authentication
4. Contact security@company.com

## Two-Factor Authentication (2FA)

For enhanced security, enable 2FA:
1. Go to Account Settings > Security
2. Click "Enable Two-Factor Authentication"
3. Scan the QR code with your authenticator app
4. Enter the verification code
5. Save your backup codes in a secure location

**Supported authenticator apps:**
- Google Authenticator
- Microsoft Authenticator
- Authy
- 1Password
